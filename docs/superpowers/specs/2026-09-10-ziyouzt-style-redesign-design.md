# 全站同系视觉重构设计

**日期**: 2026-09-10
**状态**: 已确认
**范围**: 首页与字帖工作台的全站视觉、布局、响应式和现有交互升级
**参考站**: https://ziyouzt.com/

---

## 背景

当前应用以工作台为唯一入口，`LandingPage`、`BrandHeader`、`HeroSection`、`StatsSection`、`FeatureCards`、`Testimonials` 和 `SiteFooter` 已存在，但没有接入 `App`。工作台同时混用 Bootstrap 默认样式、内联样式和独立设计系统，首页无法承担产品介绍与功能分流，桌面端宽屏空间也没有被充分利用。

参考站采用蓝紫粉品牌渐变、浅色网格背景、满屏首屏、产品演示框、能力指标、功能卡片和深色页脚。本次改造继承这套现代教育工具的视觉语言，但不复制参考站的品牌、文案、运营数字或未经证实的口碑内容。

## 目标

- 建立首页与工作台双视图，首页负责介绍与分流，工作台负责配置与生成。
- 用统一的颜色、字体、间距、圆角、阴影、按钮、表单和反馈样式替换现有混合视觉。
- 桌面工作台改为左侧配置、右侧粘性实时预览，提升长表单场景下的操作效率。
- 首页和工作台均支持浅色、深色主题和移动端布局。
- 保留现有生成、选文、AI 提示词、预览、打印和导出能力。
- 用真实产品能力替代虚构统计和口碑。

## 非目标

- 不新增搜索、登录、付费、模板市场、云端存储或后端服务。
- 不修改字帖生成算法、数据格式、分页规则或导出逻辑。
- 不引入路由库、状态管理库、UI 组件库或网络字体。
- 不复制“自优字帖”的品牌名、版权文案、运营数据或用户评价。
- 不把现有“数字字母”能力宣传为尚未实现的完整数学口算或竖式计算。

## 设计决策

### 1. 页面架构

应用继续由 `App` 管理顶层状态，使用 URL hash 表示视图，不引入路由依赖。

| URL | 视图 | 说明 |
|-----|------|------|
| `/` | 首页 | 无 hash 时默认打开首页 |
| `#/builder` | 工作台 | 打开当前步骤，生成类 CTA 的默认入口 |
| `#/builder/hanzi` | 工作台 | 预选汉字练习并进入“选内容” |
| `#/builder/pinyin` | 工作台 | 预选拼音练习并进入“选内容” |
| `#/builder/english` | 工作台 | 预选英文格式并进入“选内容” |
| `#/builder/digits` | 工作台 | 预选数字与字母练习并进入“选内容” |

无效 hash 回退到首页。视图切换时同步 `window.history`，支持浏览器前进、后退和刷新恢复。切换后滚动到顶部，并把焦点移动到当前页面的主标题。

### 2. 首页信息架构

首页按以下顺序组合：

1. 粘性 `BrandHeader`：品牌、首页、四类字帖、教程入口、深色模式切换。
2. `HeroSection`：满屏或接近满屏的双栏首屏，左侧价值主张和主 CTA，右侧产品界面演示框。
3. `StatsSection`：四项真实能力指标，不使用用户量、下载量或评分。
4. `FeatureCards`：汉字、拼音、英文、数字与字母四种入口。
5. `WorkflowSection`：选内容、选样式、生成与导出三个步骤。
6. `UseCasesSection`：家长辅导、教师备课、课后巩固等真实使用场景，替代无来源评价。
7. 渐变 CTA：进入工作台，并根据用户选择预选内容类型。
8. `SiteFooter`：品牌、导航、功能说明和版权；仅在已有备案信息时展示备案项。

首页内容必须与现有能力一致。四类入口的预选映射如下：

| 首页入口 | 工作台设置 |
|----------|------------|
| 汉字 | `feature='汉字练习'`、`copybookType='汉字字帖'`、`gridType='田字格'` |
| 拼音 | `feature='汉字练习'`、`copybookType='拼音字帖'`、`gridType='拼音格'` |
| 英文 | `feature='字帖模板'`、`layout='英文格式'`、`gridType='四线三格'`、`cols>=10` |
| 数字与字母 | `feature='数字字母'`、`gridType='四线三格'` |

进入工作台只更新这些预选项，不覆盖用户已经保存的文本、网格颜色、纸张和其他设置。

### 3. 工作台结构

桌面工作台保留“选内容、选样式、生成字帖”三步语义，但改为应用工作台布局。

```text
┌──────────────────────────────────────────────────────────────┐
│ BrandHeader: 首页 | 汉字 | 拼音 | 英文 | 数字字母 | 深色切换 │
├──────────────────────────────────────────────────────────────┤
│ StepBar: 1 选内容  >  2 选样式  >  3 生成字帖                │
├──────────────────────────────┬───────────────────────────────┤
│ 配置区域                     │ 实时预览区域                  │
│ - 当前步骤表单               │ - sticky                     │
│ - 内容库                     │ - 自动更新                   │
│ - AI 提示词折叠区            │ - 打印与导出入口             │
└──────────────────────────────┴───────────────────────────────┘
```

工作台规则：

- `> 1024px`：左右双栏，左侧配置，右侧粘性预览；页面滚动时预览保持在视口内。
- `768–1024px`：左栏变窄，预览移动至配置下方并支持展开；不保留粘性。
- `< 768px`：恢复纵向步骤流，预览使用全屏弹窗，底部固定主要操作栏。
- 第三步“生成字帖”保留全宽预览和导出工具条。
- `AIGenerationPanel` 保留在工作台配置区域，默认折叠，展开后沿用现有功能。
- 现有 `QuickGenerateBar`、`PreviewPanel`、`PreviewModal` 继续承担移动端和导出操作，不拆分业务逻辑。

### 4. 视觉系统

全站统一使用 CSS 自定义属性定义设计令牌。

**品牌色**

| 令牌 | 值 | 用途 |
|------|----|------|
| `--brand-primary` | `#2563eb` | 主操作、链接、焦点 |
| `--brand-secondary` | `#7c3aed` | 渐变中段、次级强调 |
| `--brand-accent` | `#ec4899` | 渐变末端、局部强调 |
| `--gradient-brand` | `linear-gradient(135deg, #2563eb, #7c3aed 48%, #ec4899)` | 主按钮与品牌标识 |

**中性色**

- 浅色背景使用 `#f8fafc` 和 `#f1f5f9`，正文使用 `#1f2937`，次级文本使用 `#64748b`。
- 深色主题使用深蓝黑基底，不使用纯黑；保持品牌渐变的饱和度和可读性。
- 边框使用低对比冷灰色，避免大面积高饱和描边。

**形状与空间**

- 操作控件圆角 `10–12px`，内容卡片圆角 `18–24px`，胶囊控件 `999px`。
- 使用 4px 基准间距；首页区块垂直间距 `72–112px`，工作台控件间距 `8–16px`。
- 阴影采用柔和双层阴影；悬浮增加抬升和低透明度紫色光晕。

**排版**

- 继续使用系统中文字体栈，不加载网络字体。
- 首页主标题桌面 `48–64px`，移动端 `34–42px`；正文行高不低于 `1.65`。
- 工作台标题和控件字号低于营销标题，避免在紧凑工具界面使用首屏级字号。

### 5. 组件规范

- `BrandHeader`：桌面导航居中，移动端使用抽屉；滚动后使用半透明背景和模糊。
- `HeroSection`：桌面双栏，左侧文案，右侧产品界面演示；移动端单栏并缩小装饰，不自动播放视频。
- `StatsSection`：四项真实能力指标，渐变背景，图标使用简单线性图形。
- `FeatureCards`：四张同尺寸卡片，包含图标、标题、能力描述和进入工作台动作；卡片高度稳定。
- `WorkflowSection`：三步流程，使用数字、标题和短说明，不使用装饰性时间线。
- `UseCasesSection`：三张场景卡，内容来自实际使用场景，不冒充用户评价。
- 按钮：主要操作用品牌渐变，次要用白底描边，危险操作用语义红色。
- 表单：统一边框、焦点环、禁用态和帮助文本；保留 Bootstrap 栅格，不保留其默认视觉。
- 预览：统一纸张阴影、工具栏、缩放控件和移动端弹窗。

### 6. 动效

动效强度采用“克制但有生命感”：

- 首页区块首次进入视口时淡入并上移 `12–20px`。
- 卡片悬浮上移 `2–4px`，阴影略微增强。
- 主 CTA 使用缓慢的光泽或渐变位移动效。
- 品牌 Header 在滚动后切换模糊背景。
- 工作台仅保留状态切换、折叠、悬浮、加载和 Toast 动效。
- 所有动效必须响应 `prefers-reduced-motion: reduce`，关闭时不得丢失信息或操作能力。

### 7. 深色主题

保留现有 `settings.darkMode` 手动切换和本地存储逻辑。首页和工作台使用同一套深色令牌；深色模式不能只做颜色反转，需要分别定义背景、表面、边框、文字、阴影和表单状态。

深色模式验收重点：

- 品牌渐变按钮与背景有足够对比。
- 工作台表单、选中态、错误态和禁用态可辨识。
- 预览纸张仍表示实际导出外观，不因应用主题改变打印内容。

### 8. 状态与数据流

现有业务 Hooks 和状态边界保持不变：

- `useSettings` 继续负责设置读取、更新和本地存储。
- `useCourseData` 继续负责年级、学科、单元、课文和生字。
- `useCopybook` 继续负责分页、预览、随机内容、导出和特殊字帖逻辑。
- `useStepFlow` 继续负责三步状态。

新增的顶层数据流只负责：

1. 从 URL 解析首页或工作台视图。
2. 把首页功能类型映射为现有设置值。
3. 写入 URL hash、更新视图、滚动和焦点。
4. 把 `currentView`、`onNavigate` 和 `onStartBuilder` 传入首页组件。

刷新页面时由 `useSettings` 恢复已保存设置。工作台步骤不强制持久化；刷新后允许回到第一步，但不得清空已保存内容。

### 9. 错误与可访问性

- 继续使用 `ErrorBoundary` 捕获渲染错误，继续使用现有 Toast 展示可恢复错误。
- 无效 URL hash 回退首页，不显示空白页。
- 页面切换后移动焦点到主标题；动态内容变化使用现有 Toast 或 `aria-live` 区域。
- 导航、步骤条、按钮、表单和抽屉支持键盘操作，并保留清晰焦点环。
- 装饰用网格、光晕和演示框从无障碍树中排除。
- 点击目标和文字在移动端不得重叠；固定底栏不能遮挡最后一项内容。

## 测试策略

### 自动化

- 运行 `npm run build`，确保生产构建通过。
- 运行现有 `npm run test:unit`，确保业务 Hooks 和工具函数无回归。
- 运行 Playwright 测试，覆盖以下路径：
  - 默认打开首页，无 hash。
  - 点击四种功能卡后打开工作台并写入正确预选项。
  - 浏览器前进、后退和刷新后视图与 hash 一致。
  - 工作台三步切换、内容选择、AI 面板、预览和导出按钮仍可操作。
  - 移动端恢复步骤流，抽屉和预览弹窗可打开、关闭。
  - 深色主题下首页和工作台关键内容可见。

### 视觉回归

在以下视口检查首页和工作台：

- `1440×900`
- `1024×768`
- `390×844`

每个视口至少覆盖浅色、深色，以及工作台预览展开状态。检查项包括：

- 无横向滚动和页面级溢出。
- 导航、步骤条、卡片和按钮文字不截断、不重叠。
- 桌面粘性预览不跳动，移动端固定底栏不遮挡内容。
- 空状态、加载态、错误态、禁用态和焦点态清晰可见。
- 演示框和图标正常渲染，不依赖外部网络资源。

## 验收标准

满足以下条件视为完成：

1. 打开应用默认看到首页，而不是直接进入工作台。
2. 首页完整呈现品牌导航、首屏、真实能力指标、四类入口、三步流程、使用场景、CTA 和页脚。
3. 首页与工作台视觉体系一致，不再出现明显 Bootstrap 默认外观和内联样式冲突。
4. 桌面工作台为左侧配置、右侧粘性预览；移动端为纵向步骤流。
5. 深色模式可切换且在两个视图均可用。
6. 四种首页入口能正确预选工作台类型，同时不覆盖用户已有设置。
7. 选内容、AI 提示词、实时预览、打印和所有现有导出能力无回归。
8. 自动化测试、生产构建和指定视口视觉检查全部通过。
9. 首页不展示无法核验的用户量、下载量、评分或冒充真实用户的评价。

## 已确认的选择

- 改造范围：全站视觉与交互统一。
- 视觉方向：同系重构，继承参考站的蓝紫粉渐变、玻璃质感、满屏首屏和产品演示框。
- 信息架构：首页到工作台的双视图。
- 数据表达：真实能力指标和真实使用场景。
- 动效强度：克制但有生命感。
- 桌面工作台：左侧配置、右侧粘性预览。
- 深色主题：保留并统一升级。
