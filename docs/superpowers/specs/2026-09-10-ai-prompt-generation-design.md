# AI 提示词生成功能设计

**日期**: 2026-09-10
**状态**: 已确认
**范围**: 在现有 AIGenerationPanel 中新增「生成提示词」Tab

---

## 背景

当前 `AIGenerationPanel` 直接调用本地 Ollama API 生成字帖内容。用户希望新增一种模式：AI 根据用户需求生成一段高质量的提示词，用户可复制到 ChatGPT、Claude、Midjourney 等平台自行生成内容。

## 设计决策

### 1. 架构：扩展现有面板

在 `AIGenerationPanel` 内加 Tab 切换，而非新建独立组件。

- **复用**：Ollama 连接、toast 通知、快捷提示词、输入框布局
- **最小改动**：仅新增 Tab 状态 + 提示词生成逻辑 + 复制功能
- **用户路径**：同一面板内切换，学习成本低

### 2. Tab 切换 UI

```
┌─────────────────────────────────────────┐
│  ┌──────────────┐  ┌──────────────┐     │
│  │ ✨ 直接生成   │  │ 📝 生成提示词 │     │
│  └──────────────┘  └──────────────┘     │
└─────────────────────────────────────────┘
```

- 默认选中「直接生成」，保持现有行为
- 切换 Tab 时保留用户输入内容
- 激活态：渐变底部边框 + 品牌色文字；非激活态：灰色

### 3. 输入设计

**简单模式（默认）：**
- textarea 自由描述需求
- 4 个快捷提示词按钮（提示词模式专用，如"一年级生字练习""唐诗生成""数学口算题""英语字母书写"）

**高级模式（点击 ▼ 展开）：**
- 年级选择器（一年级~六年级）
- 学科（语文/数学/英语）
- 内容类型（汉字帖/笔画帖/口算题/拼音临摹/字母书写等，根据学科动态过滤）
- 难度/数量（根据学科动态变化）
- 可选填，未填字段由 AI 智能补全

### 4. 目标平台选择

单选按钮组，位于输入区下方：

| 选项 | 图标 | 说明 |
|------|------|------|
| 对话 AI | 💬 | ChatGPT / Claude / Kimi 等，默认选中 |
| 图像 AI | 🎨 | Midjourney / Stable Diffusion 等 |

选择不同平台，生成的提示词格式不同：
- **对话AI**：自然语言指令，强调分步骤输出、格式清晰
- **图像AI**：视觉描述风格，强调构图、色彩、光线

### 5. 输出与复制体验

- 生成的提示词展示在带边框卡片中
- 右上角「📋 复制」按钮
- 点击后：
  1. `navigator.clipboard.writeText()` 复制到剪贴板
  2. 按钮变为「✓ 已复制」+ 绿色高亮
  3. 1.5 秒后恢复原状
- 降级方案：`document.execCommand('copy')`

### 6. AI 生成逻辑

复用现有 Ollama 连接（`http://localhost:11434/api/generate`，model: llama3），切换为提示词生成 system prompt：

```
你是一个提示词工程专家。根据用户需求，生成一段高质量的{platform}提示词。

要求：
1. 提示词要完整、可直接使用，用户无需修改
2. 包含角色设定、具体任务、输出格式要求
3. 字帖内容控制在合理范围（汉字20-100字，数学题10-20道）
4. 语言：中文为主，英文内容用英文
5. {platform_specific}

用户需求：{user_input}
结构化参数：{structured_params}
```

**`{platform_specific}` 差异：**
- 对话AI：「分步骤输出」「格式清晰」「适合粘贴到对话」
- 图像AI：「视觉风格描述」「构图细节」「色彩和光线」

**错误处理**：与直接生成一致，Ollama 未启动时显示友好提示。

- 不扩展提示词领域到字帖以外

## 补充说明（Self-Review 修正）

### 快捷提示词
提示词生成模式使用独立的快捷提示词，与直接生成不同：
- 直接生成：`"一年级生字：天地人你我他"` → 直接输出内容
- 生成提示词：`"一年级生字练习"` → 输出一段可复制的提示词

### 结构化参数序列化
高级模式的用户选择，序列化为文本后拼入 prompt：
```
年级：一年级 | 学科：语文 | 内容类型：汉字帖 | 数量：20字
```
未留空的字段才会拼入。
