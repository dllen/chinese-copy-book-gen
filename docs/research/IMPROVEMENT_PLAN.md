# 字帖生成器改进计划 — 参考自优字帖 (ziyouzt.com)

## 分析摘要

### 自优字帖 (ziyouzt.com) 核心特征
- **技术栈**: Nuxt.js (Vue) + Tailwind CSS，渐变蓝紫色调设计系统
- **页面结构**: 首页(hero+功能卡片+统计+评价) → 子页面(汉字/数学/拼音/英文)
- **核心功能**: 汉字帖(文章/汉字/笔画/教材)、数学帖(数字/口算/竖式)、拼音帖(临摹/写汉字)、英文字帖(字母/单词/文章)
- **亮点功能**: AI内容生成、拍照识字、实时A4预览、多字体(楷书/行书)、多种格子(田字格/米字格/回宫格)、背景图片
- **设计语言**: 渐变品牌图标(蓝→紫→粉)、sticky header+backdrop blur、卡片式布局、深色footer、社交证明(评价+数据)

### 当前项目优势
- 完整的React+Vite架构，Bootstrap响应式布局
- 三级步骤向导(选内容→选样式→生成字帖)
- 按年级/学科/单元的课程字帖系统
- 丰富的配置选项和导出功能(PDF/图片)
- 暗色模式、模板保存/加载、配置导入/导出
